# Five-minute demo script

1. Open the app and log in using the local or admin demo credentials.
2. Review the overview dashboard and filters for department, year, and risk.
3. Open a student profile and inspect the score breakdown, coverage, and historical trend.
4. Review academic and placement risk cards with evidence and intervention suggestions.
5. Enter a valid academic mark update for a mentor-authorised student.
6. Confirm score recomputation and compare before/after values.
7. Create a new intervention and mark it in progress.
8. Review import preview and validation results.
9. Open the role-matrix viewer and confirm permissions.
10. Close with a summary of the rules-based analytics and prototype boundaries.
